# Repository for storing all EECE 2560 Group Projects

**Project 1 – Mastermind Game**

Developed a C++ implementation of the Mastermind game where players guess a hidden code and receive feedback on exact and partial matches. Focused on algorithm design for evaluating guesses, input handling, and structured game flow.


**Project 2 – Flip Card Game**

Created a C++ implementation of the card game Flip using custom card and deck classes. Modeled a full 52-card deck with a linked list, including shuffling, dealing, and replacing cards, and implemented game logic with dynamic score updates based on card values and suits.


**Project 3 – Word Search Solver**

Implemented a backtracking algorithm to find and validate words within a 2D grid. The program explores all possible paths while avoiding revisiting cells, demonstrating recursion, efficient search techniques, and constraint handling.
